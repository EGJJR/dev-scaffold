# {{ project_name }}

HTTP service generated by `goldpath` (`api` template).

## Required environment

Copy `.env.example` to `.env` and set a real `SECRET_KEY`. The process exits on startup if `SECRET_KEY` is missing.

In production set `ENV=production`. That disables OpenAPI docs and rejects wildcard CORS and hosts.

## Commands

Install [uv](https://docs.astral.sh/uv/) if you do not have it, then:

```bash
uv sync --extra dev
SECRET_KEY=dev-only-not-for-production ENV=test uv run pytest
SECRET_KEY=dev-only-not-for-production ENV=development uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

If you use [just](https://github.com/casey/just), `just test`, `just run`, and `just docker` wrap the same commands.

The service listens on `127.0.0.1:8000`. `GET /health` returns `{"status":"ok"}` and does not dump configuration.

## What is included

- Pydantic request validation
- Trusted-host and CORS middleware (no `*` in production)
- Multi-stage non-root Dockerfile with a pinned base tag
- GitHub Actions: lint, test, `uv run pip-audit`, `docker build`
- Dependabot for uv, Actions, and Docker

This template is a secure starting point, not an authentication system or a vulnerability scanner.
