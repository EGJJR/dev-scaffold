# {{ project_name }}

HTTP service generated by `goldpath` (`api-rust` template).

## Required environment

Copy `.env.example` to `.env` and set a real `SECRET_KEY`. The process exits on startup if `SECRET_KEY` is missing.

In production set `ENV=production`. Wildcard CORS origins are ignored.

## Commands

```bash
SECRET_KEY=dev-only-not-for-production cargo test
SECRET_KEY=dev-only-not-for-production cargo run
docker build -t {{ project_name }}:local .
```

If you use [just](https://github.com/casey/just), `just test`, `just run`, and `just docker` wrap the same commands.

The service listens on `BIND_ADDR` (default `0.0.0.0:8000` in the binary, `127.0.0.1:8000` in `.env.example`). `GET /health` returns `{"status":"ok"}` and does not dump configuration.

## What is included

- Request body size limit and request timeout
- CORS allow-list (no `*` in production)
- Multi-stage non-root Dockerfile with a pinned base tag
- GitHub Actions: fmt, clippy, test, `cargo audit`, `docker build`
- Dependabot for Cargo, Actions, and Docker

This template is a secure starting point, not an authentication system or a vulnerability scanner.
